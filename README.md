# my-site

홍길동의 자기소개 웹사이트입니다. HTML, CSS, JavaScript만으로 만들었고 빌드 도구나 npm 패키지는 사용하지 않습니다.

## 배포 주소

https://vpansfl.github.it/my-site/

## 로컬에서 보는 방법

1. 이 저장소를 내려받거나 클론합니다.
2. 탐색기에서 `index.html`을 더블클릭하거나, 브라우저로 파일을 끌어다 놓습니다.

또는 간단한 로컬 서버로 띄울 수 있습니다. Python이 설치되어 있다면 프로젝트 폴더에서 아래 명령을 실행한 뒤 `http://localhost:8000`에 접속합니다.

```bash
python -m http.server 8000
```

## 파일 구성

- `index.html`: 페이지 구조와 내용
- `style.css`: 스타일
- `script.js`: 동작 스크립트
